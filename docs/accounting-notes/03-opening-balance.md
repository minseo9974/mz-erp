# 회계 노트 03 — 기초잔액과 전기분 재무상태표

**전산회계 1급 연결**: 실무시험의 "전기분 재무제표" 입력·수정 (전기분 재무상태표, 거래처별 초기이월).

## 1. 기초잔액이란

회사는 프로그램을 쓰기 전부터 영업을 해 왔습니다. 프로그램을 처음 쓰는 해에는 **직전 연도 말의 재무상태표**(전기분 재무상태표)를 옮겨 적어야 올해 장부가 맞는 숫자에서 출발합니다.

- 전기 말 현금 5,000,000이 있었다면, 올해 1월 1일 현금 계정은 5,000,000에서 시작
- 이 "시작 숫자"가 **기초잔액**(전기이월)

## 2. 들어가는 계정과 들어가지 않는 계정

| 들어감 | 들어가지 않음 |
| --- | --- |
| 자산 · 부채 · 자본 (재무상태표 계정) | 수익 · 비용 (손익계산서·제조원가 계정) |

수익·비용은 **한 해 동안의 흐름**이라 해가 바뀌면 0에서 다시 시작합니다. 전기의 순이익은 이미 **이월이익잉여금**(자본)에 합쳐져 넘어옵니다.

그래서 전기분 재무상태표는 항상 **자산 = 부채 + 자본**이고, 전표로 쓰면 차변 합계 = 대변 합계가 됩니다.

**차감 계정에 주의**: 대손충당금·감가상각누계액은 자산 쪽에 표시되지만 **대변** 잔액입니다. 외상매출금 20,000,000 / 대손충당금 200,000이면 차변 20,000,000, 대변 200,000으로 적습니다 (순액 19,800,000으로 합쳐 적지 않음).

## 3. 거래처별 초기이월

외상매출금·외상매입금처럼 **거래처가 필요한 계정**은 합계만 넣으면 안 됩니다. 누구에게 얼마인지 나눠 넣어야 올해 회수·지급을 거래처원장에서 맞춰 볼 수 있습니다.

| 계정 | 거래처 | 금액 |
| --- | --- | ---: |
| 108 외상매출금 | 00101 (주)한빛전자 | 12,000,000 |
| 108 외상매출금 | 00102 (주)새솔테크 | 8,000,000 |

## 4. 우리 시스템에서는 — 전표 한 장

기초잔액을 별도 표에 두지 않고 **회계연도 첫날의 OPENING 전표 한 장**으로 넣습니다 ([ADR-0004](../adr/0004-opening-balance-as-journal.md), 불변식 5). 장부는 전표 라인만 더하면 되고, 기초잔액만 따로 더하는 경로가 없습니다.

- **첫 회계연도에만** 직접 입력합니다. 다음 해부터는 연도 마감(차기이월)이 자동으로 만듭니다 (5단계)
- 다른 전표와 같은 규칙을 따릅니다: 임시 저장 → 고쳐 쓰기 가능 → **전기하면 불변**. 전기한 뒤 틀린 것을 발견하면 역분개하고 다시 입력합니다
- 살아 있는 기초잔액 전표는 회계연도당 한 장입니다 (역분개된 것은 세지 않음)
- 수익·비용 계정은 넣을 수 없습니다 (앱 검사 + DB 트리거)

시나리오 회사의 기초잔액은 [scenario/company.md](../scenario/company.md)에 있습니다. 차변·대변 합계는 각각 138,000,000입니다.

## 스스로 확인

- [ ] 전기 말 재무상태표에 "외상매출금 20,000,000, 대손충당금 (200,000)"이라고 적혀 있다. 기초잔액 전표에서 각각 차변·대변 어느 쪽인가?
- [ ] 전기에 순이익 5,000,000이 났다. 기초잔액 전표의 어느 계정에 들어 있는가?
- [ ] 기초잔액 전표를 전기한 뒤 보통예금 금액이 틀린 것을 발견했다. 어떻게 고치는가?
