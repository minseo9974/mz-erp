# 회계 노트 01 — 복식부기와 차변·대변

> 전산회계 1급 연결: 이론 "회계의 기본 원리", 실무 "일반전표 입력" 전체

## 한 줄 요약
모든 거래는 **두 계정 이상에 같은 금액으로** 기록된다. 그래서 차변 합계와 대변 합계는 항상 같고,
이 성질이 시스템 전체 검증의 기반이 된다 (불변식 1).

## 거래의 8요소
차변(왼쪽)과 대변(오른쪽)에 무엇이 오는지는 정해져 있다.

| 차변 (왼쪽) | 대변 (오른쪽) |
| --- | --- |
| 자산 증가 | 자산 감소 |
| 부채 감소 | 부채 증가 |
| 자본 감소 | 자본 증가 |
| 비용 발생 | 수익 발생 |

## 시나리오 회사로 보는 예

**1) 원재료 1,100,000원(부가세 포함)을 외상으로 매입** — 매입매출전표 51 과세

| 차변 | 금액 | 대변 | 금액 |
| --- | ---: | --- | ---: |
| 153 원재료 (자산 증가) | 1,000,000 | 251 외상매입금 (부채 증가) | 1,100,000 |
| 135 부가세대급금 (자산 증가) | 100,000 | | |

**2) 외상매입금 1,100,000원을 보통예금으로 지급** — 일반전표

| 차변 | 금액 | 대변 | 금액 |
| --- | ---: | --- | ---: |
| 251 외상매입금 (부채 감소) | 1,100,000 | 103 보통예금 (자산 감소) | 1,100,000 |

## 정상잔액과 차감계정
- 계정의 잔액은 "늘어나는 쪽"에 남는다: 자산·비용은 차변, 부채·자본·수익은 대변
- **차감계정**은 예외: 감가상각누계액은 자산(기계장치)을 깎는 계정이라 **대변**에 쌓인다.
  재무상태표에서는 기계장치 50,000,000 아래 (10,000,000)으로 표시되어 장부금액 40,000,000이 된다
- 그래서 시스템은 계정 대분류가 아니라 `normal_balance` 속성으로 잔액 방향을 계산한다 ([account-chart.md](../design/account-chart.md))

## 코드로 옮길 때
- 전표 라인은 차변 금액 또는 대변 금액 **한쪽만** 가진다 (DB CHECK)
- 전표 저장 시 Σ차변 = Σ대변 검증 (앱 + DB 트리거, [ADR-0006](../adr/0006-balance-check-in-app-and-db.md))
- 원장 잔액 = 정상잔액이 차변이면 Σ차변 − Σ대변, 대변이면 Σ대변 − Σ차변
