# MZ-ERP 개요

## 최종 목표

**회계팀 신입이 실무를 처음부터 끝까지 연습하는 사이트** — 이론은 배웠지만 실무는 처음인 사람이 들어와서, 증빙을 보고 전표를 치고 장부·부가세·결산을 거쳐 재무제표까지 직접 만들어 본다.

그 바닥은 직접 구현한 회계 ERP다. "거래 하나가 재무제표에 반영되기까지 제 코드로 설명할 수 있다"는 처음의 목표는 그대로이고, 그 위에 실습 층을 얹는다 (2026-11-10 전환 — [design/training-site.md](design/training-site.md), ADR-0012~0015). 2027년 4월까지 배포한다.

| 목표 | 완료 기준 |
| --- | --- |
| 실무 한 바퀴 | 사용자가 0~7장을 미션으로 완주해 재무제표를 만들고 이월한다 (8장 종합 실전은 그 위의 심화) |
| 회계 흐름 전체 구현 | 전표 → 원장 → 시산표 → 결산 → 재무제표 → 차기이월을 한 회계연도 끝까지 |
| 정확성 | 시나리오 전체 재생 결과가 검산된 정답과 일치, 모든 미션이 CI에서 검증됨 |
| 피드백 품질 | 원인을 짚는 오답 유형 8종 이상 ('전표 없음'·'그 밖' 제외, 지금 범용 6종 + 미션 오답 예시 `MISTAKE`) + 미션마다 오답 예시와 전용 반려 사유 (CI 검증) |
| 범위 | 전산회계 1급 실무 유형 ↔ 미션 커버리지 표에 빈칸이 없다 (뺀 유형은 이유를 적는다) |
| 진입 장벽 | 가입 없이 1분 안에 첫 미션 |
| 품질 | 회계 불변식 테스트 전부 통과, 도메인 코드 커버리지 80% 이상 |
| 성능 | 전표 100만 건에서 월 합계잔액시산표 p95 2초 이내 (목표치) |
| 배포 | 공개 URL, CI/CD 자동 배포 |
| 문서 | README, ADR, 엔진 해설, 기술 블로그 3편 이상 |

**하지 않을 것**: 실제 세무 신고·홈택스 연동·세무 상담, 급여·4대 보험 계산(급여대장은 주어진 자료), 재고 수불, 다중 통화, 연결재무제표, 여러 업종 과정, 강의 영상·결제·커뮤니티. AI 튜터는 규칙 기반 피드백이 자리 잡은 뒤.

## 단계

0~2단계는 처음 계획보다 일찍 끝나 날짜를 실제 진행에 맞췄다. 뒤 단계의 기간은 주 10시간 기준 어림이며 L1의 실제 소요를 보고 다시 잡는다.

| 단계 | 기간 | 완료 조건 |
| --- | --- | --- |
| 0. 설계 | 2026-11-09 완료 | 시나리오 회사 거래 목록과 정답 재무제표 확정 |
| 1. 기반 구축 | 코드 완료, 서버 보류 | PR 하나가 CI를 거쳐 운영 서버까지 자동 배포 |
| 2. 전표 엔진 | ~11월 말 | 차대·불변·동시성 테스트 + 1년치 재생 골든 테스트 통과 |
| **L1. 실습 세로 조각** | 12월 | 게스트로 들어와 0~1장을 끝까지 완주 (완주 E2E 통과) |
| 3. 장부·시산표 + 2장 | 2027-01 | 시산표 불변식 + 잔액 재집계 일치 / 판독·대사·첫 월 마감 미션 (기간 마감 기능을 5단계에서 당김) |
| 4. 매입매출·부가세 + 3·4장 | 02 | 부가세 시나리오 정답 일치 / 세금계산서 등 증빙, 첫 부가세 신고 |
| 5. 결산·재무제표·이월 + 5·6·7장 | 03 | 1년치 골든 테스트 통과 / 하반기부터 결산·재무제표·이월까지 미션 |
| 6. 고정자산·채권·권한 + 8장 | 04 초 | 상각·권한 거부 테스트 / 종합 실전: 오류 찾기·결재자 역할 |
| 7. 배포·성능·문서화 | 04 | 성능 목표, 전 과정 완주 E2E, 콘텐츠 전체 재검증, 수료 리포트, 블로그 3편 |

L1을 3단계보다 먼저 하는 이유: 엔진은 만드는 법을 알지만 "미션으로 실무를 가르치는 경험"은 만들어 봐야 안다. 가장 불확실한 것을 가장 먼저 작게 확인한다.

> 2026-11-24: 장을 주제별에서 **달력 순서**로 바꿨다 — 0 입사 첫날 · 1 전표의 기본(1~3월) · 2 첫 월 마감 · 3 매입과 매출(4~6월) · 4 첫 부가세 신고 · 5 하반기 · 6 결산 · 7 재무제표와 이월 · 8 종합 실전. 아직 맡지 않은 거래는 선배(시스템)가 처리한다 ([ADR-0016](adr/0016-course-follows-calendar.md), 장 구성은 [training-site.md §4](design/training-site.md#4-커리큘럼-az)). 위 표의 장 번호는 새 구성이다.

### 장 완료 정의

장 하나를 "끝났다"고 하려면 (3단계부터 매 장, L1의 1장에도 적용):

- 미션 · 해설(근거 조문·기준 연도) · 오답 예시가 있고 CI를 통과한다
- 그 장의 완주 E2E가 있다
- [콘텐츠 검증 절차](design/training-site.md#콘텐츠-검증-절차-실무자-검수-대신)를 거쳤다: 근거 조문 확인, 기출 대조, 독립 재검토 (실무자 검수자가 없어 이것으로 대신한다)

그러면 7단계의 "전 과정 완주 E2E · 콘텐츠 재검증"은 장마다 쌓인 것을 한 번에 다시 돌리는 일로 줄어든다.
