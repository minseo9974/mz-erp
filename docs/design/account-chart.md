# 계정과목 체계

계정과목은 단순한 이름 목록이 아니라 **시스템의 행동을 정하는 설정**입니다. 원장에서 잔액을 어느 방향으로 계산할지,
재무제표 어디에 표시할지, 거래처가 꼭 있어야 하는지를 전부 계정 속성으로 판단합니다. 그래서 코드에 `if (code == 108)` 같은
분기를 쓰지 않습니다 ([CLAUDE.md](../../CLAUDE.md) 불변식 6).

> **코드 번호에 대해**: 전산회계 1급 시험 프로그램(KcLep)의 번호 관행(101 현금, 108 외상매출금 …)을 따르려 했지만
> 기억에 의존해 정리한 부분이 있습니다. 공부하면서 실제 프로그램과 대조하고, 다른 번호는 고칩니다 (0단계 체크리스트).

기계가 읽는 원본은 [data/seed/accounts.csv](../../data/seed/accounts.csv)입니다. 이 문서와 CSV가 다르면 CSV가 기준이고, 1단계에서 Flyway 시드로 그대로 씁니다.

## 계정 속성

| 속성 | 값 | 쓰이는 곳 |
| --- | --- | --- |
| `category` (대분류) | ASSET 자산 · LIABILITY 부채 · EQUITY 자본 · REVENUE 수익 · EXPENSE 비용 | 재무제표 구분, 결산 시 손익 대체 대상 판별 |
| `subgroup` (중분류) | 당좌자산, 재고자산, 투자자산, 유형자산, 무형자산, 기타비유동자산, 유동부채, 비유동부채, 자본금, 자본잉여금, 자본조정, 이익잉여금, 매출, 매출원가, 제조원가, 판매비와관리비, 영업외수익, 영업외비용, 법인세 | 재무제표 소계 |
| `normal_balance` | DEBIT 차변 · CREDIT 대변 | 원장 잔액 계산 방향 |
| `contra_of` | 차감 대상 계정 | 재무제표에서 대상 계정 아래에 차감 표시 |
| `requires_partner` | true / false | 전표 라인에 거래처가 없으면 저장 거부 |
| `statement` | BS 재무상태표 · IS 손익계산서 · MC 제조원가명세서 · SYS 시스템 | 표시할 재무제표 |
| `is_system` | true / false | 사용자가 직접 전표에 쓰지 못하는 계정 (결산용 400 손익) |

**정상잔액 규칙**: 자산·비용은 차변, 부채·자본·수익은 대변이 기본입니다. 예외는 **차감계정**으로,
대손충당금과 감가상각누계액은 자산이지만 대변 잔액입니다. `category`만 보고 방향을 정하면 이 계정들에서 틀리기 때문에
`normal_balance`를 별도 속성으로 둡니다.

## 설계 메모

- **같은 이름, 다른 계정**: 급여(503 제조 / 801 판관), 감가상각비(518 / 818)처럼 이름이 같아도 코드가 다르면 다른 재무제표로 갑니다. 화면에서는 반드시 코드와 이름을 함께 보여줍니다.
- **계산으로 만들어지는 계정**: 501 원재료비, 455 제품매출원가는 평소 전표로 쌓이지 않고 결산 때 재고 수치로 계산해 분개합니다. 전산회계 1급 결산 문제의 핵심이므로 `accounting-notes`에 별도 노트를 씁니다.
- **회사별 계정**: 계정표는 `company_id` 단위입니다. 새 회사를 만들면 이 표준 계정표를 복사해 시작합니다.
