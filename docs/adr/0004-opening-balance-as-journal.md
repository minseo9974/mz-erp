# ADR-0004: 기초잔액도 전표로 넣는다

- 상태: 채택 (2026-11-09)

## 맥락
기초잔액을 별도 테이블에 두면 원장·시산표 쿼리가 "기초잔액 테이블 + 전표 라인"을 매번 합쳐야 하고,
두 경로 중 하나만 고치는 버그가 생기기 쉽다.

## 결정
- 회계연도 첫날에 `entry_type = OPENING` 전표 한 장으로 기초잔액을 넣는다
- 첫 해는 "전기분 재무상태표" 화면에서 입력 → OPENING 전표 생성
- 다음 해부터는 차기이월(연도 마감) 기능이 OPENING 전표를 자동 생성
- 수익·비용 계정은 OPENING 전표에 들어갈 수 없다 (연도 마감에서 이익잉여금으로 대체됐어야 함)

## 결과
- 좋은 점: 모든 장부가 "전표 라인 집계" 한 경로로 나옴 (불변식 5)
- 감수할 점: 기초잔액 조회 시 entry_type 필터가 필요. 기간별 원장에서 "전기이월" 행은 OPENING 전표로 표시
