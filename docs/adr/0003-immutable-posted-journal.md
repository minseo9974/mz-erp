# ADR-0003: 전기된 전표는 고치지 않고 역분개로 정정한다

- 상태: 채택 (2026-11-09)

## 맥락
이미 장부에 반영된 전표를 직접 고치면 과거 시점의 장부·신고 자료가 소리 없이 바뀐다.
감사(audit) 관점에서 "언제 무엇이 왜 바뀌었는지"가 사라진다.

## 결정
- 전표 상태는 `DRAFT → POSTED` 두 단계. 승인 = 전기
- POSTED 전표와 그 라인은 UPDATE/DELETE 불가 (앱 검증 + DB 트리거)
- 정정은 **역분개 전표(REVERSAL)**: 원전표의 차대를 뒤집은 전표를 만들고 `reversal_of_id`로 연결한 뒤, 올바른 전표를 새로 입력
- 역분개 일자는 원전표가 속한 기간이 마감됐으면 정정하는 날짜로 한다

## 결과
- 좋은 점: 모든 변경 이력이 전표로 남음, 마감 이후 숫자가 바뀌지 않음
- 감수할 점: 오타 하나도 전표 2장이 더 생김 → DRAFT 단계에서 충분히 검토하도록 화면 설계
- 승인과 전기를 분리하지 않은 이유는 [erd.md](../design/erd.md) "전표 상태" 참고
