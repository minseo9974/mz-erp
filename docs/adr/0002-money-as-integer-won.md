# ADR-0002: 금액은 원 단위 정수로 다룬다

- 상태: 채택 (2026-11-09)

## 맥락
`double`은 0.1 + 0.2 ≠ 0.3 같은 오차가 생긴다. 회계에서 1원 오차는 차대 불일치, 시산표 불일치로 이어진다.
원화만 다루고(다중 통화는 범위 밖), 국내 회계·세무 금액은 원 단위다.

## 결정
- DB: `NUMERIC(18,0)`
- 코드: `Money` 값 객체(내부 `long`). 더하기·빼기·비교만 허용하고, 곱셈·나눗셈은 **단수처리 규칙을 인자로 받는** 메서드로만 제공
- 부가세 = 공급가액 × 10%의 원 미만은 **절사**를 기본으로 하고, 단수처리 규칙은 `VatCalculator` 한 곳에만 둔다
- 감가상각 등 나눗셈이 있는 계산도 단수처리 방식을 명시한다

## 결과
- 좋은 점: 오차 원천 차단, 단수처리가 한 곳에 모여 테스트하기 쉬움
- 감수할 점: 외화·소수 단가가 필요해지면 재설계 필요 (범위 밖으로 둠)
